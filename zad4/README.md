## Вопросы для самоподготовки

### Базовые понятия

1. Что такое облако точек? Какие данные оно обычно содержит?

Набор точек в 3D-пространстве, представленный координатами (X, Y, Z). Дополнительно может содержать: интенсивность отражения, RGB-цвета, нормали, временные метки, классификацию.

2. Что такое скалярное поле в контексте облака точек?

Числовое значение, присвоенное каждой точке облака. Одна точка = одно скалярное значение. Формально: функция f: P → R, где P - множество точек.

3. Как можно связать скалярное поле с точками?

Через индексацию массивов: каждому индексу точки соответствует значение в массиве скаляров. В NumPy: `scalar_field[i]` соответствует `points[i]`.

4. Приведите примеры реальных скалярных полей.

LIDAR: интенсивность отражения, количество возвратов. Фотограмметрия: достоверность реконструкции, текстурная информация. Топография: высота над уровнем моря, уклон. Сканирование: температура поверхности, шероховатость.

### Работа со скалярными полями в NumPy

5. Как с помощью NumPy создать массив скалярных значений для точек?

`scalar_field = np.full(n_points, value)` - постоянное значение. `scalar_field = np.random.uniform(min, max, n_points)` - случайные значения. `scalar_field = points[:, 2]` - использовать координату.

6. Как добавить к каждому значению скалярного поля постоянную величину?

`scalar_field += constant` или `scalar_field = scalar_field + constant`. Векторизованная операция, применяется ко всем элементам.

7. Как умножить все значения скалярного поля на коэффициент?

`scalar_field *= coefficient` или `scalar_field = scalar_field * coefficient`. Broadcasting автоматически применяет операцию поэлементно.

8. Что произойдёт с данными при нормализации скалярного поля в диапазон [0, 1]?

Все значения масштабируются линейно: минимум становится 0, максимум становится 1. Сохраняется относительное распределение. Формула: `(x - min) / (max - min)`.

9. Какие статистические параметры можно вычислить для скалярного поля?

Центральные тенденции: среднее, медиана, мода. Разброс: std, дисперсия, min, max, квантили. Форма распределения: асимметрия, эксцесс.

10. Как интерпретировать значения: минимум, максимум, среднее, дисперсия?

Min/max - границы диапазона данных. Среднее - типичное значение, центр масс распределения. Дисперсия (std²) - мера разброса относительно среднего. Высокая дисперсия = большая вариативность.

### Обработка и анализ

11. Для чего используется гауссов фильтр при обработке скалярных полей?

Сглаживание шума с сохранением важных особенностей данных. Работает как взвешенное среднее, где веса определяются функцией Гаусса. Параметр sigma контролирует степень сглаживания.

12. Чем отличается гауссов фильтр от скользящего среднего?

Гауссов: взвешенное среднее с убывающими весами (плавное сглаживание). Скользящее среднее: равные веса для всех точек окна (грубое сглаживание). Гаусс лучше сохраняет локальные особенности.

13. Как можно визуализировать скалярное поле, используя цветовую карту?

Нормализовать значения в [0, 1], применить colormap: `colors = plt.cm.viridis(normalized_values)`. Результат - RGB-цвета для каждой точки. Позволяет визуально оценить распределение значений.

14. Зачем может понадобиться использовать скалярное поле в качестве координаты?

Визуализация абстрактных зависимостей в 3D. Деформация геометрии на основе данных. Создание рельефа из 2D-данных. Например, построить высоту по температуре.

15. Что произойдёт с визуализацией, если применить некорректную нормализацию?

При делении на 0 (min=max): все значения станут NaN/inf. При неправильном диапазоне: потеря контраста или выход за границы colormap. Артефакты в цветовой карте.

### Интерполяция и фильтрация

16. Как можно обнаружить пропущенные значения в скалярном поле?

`np.isnan(scalar_field)` возвращает маску булевых значений. `np.isnan(scalar_field).sum()` - количество NaN. `np.where(np.isnan(scalar_field))` - индексы пропусков.

17. Что такое интерполяция и как она может быть реализована в NumPy/Scipy?

Восстановление значений между известными точками. Scipy: `interp1d` для 1D, `griddata` для 2D/3D. Методы: линейная, кубическая, nearest-neighbor. Позволяет заполнить пробелы в данных.

18. Как отфильтровать точки по условию, заданному на значения скалярного поля?

Создать булеву маску: `mask = (scalar_field >= min_val) & (scalar_field <= max_val)`. Применить: `filtered_points = points[mask]`, `filtered_scalar = scalar_field[mask]`.

### Задания с анализом

21. Почему важно сглаживать скалярные поля перед анализом?

Удаление шума, который может исказить результаты. Выявление истинных трендов без артефактов измерений. Улучшение работы алгоритмов обработки (например, детекция границ).

22. Что будет, если применить гауссов фильтр с очень большим значением σ?

Чрезмерное сглаживание: потеря важных деталей и локальных особенностей. Все значения стремятся к среднему. Результат становится практически однородным. Теряется информативность данных.

23. Как можно визуально определить наличие шума в скалярном поле?

Хаотичные, резкие изменения цвета при визуализации. Высокочастотные колебания на графиках. Отклонения от ожидаемых плавных паттернов. Выбросы (outliers) на гистограмме распределения.

24. Можно ли применить скалярное поле как Z-координату, если оно содержит пропуски (NaN)? Почему?

Нет, нельзя напрямую. NaN в координатах сделает точки невалидными для визуализации и обработки. Решение: сначала интерполировать пропуски, затем использовать как координату. Или удалить точки с NaN.
