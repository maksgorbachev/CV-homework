## Вопрос 1: Какие категории классифицируются хуже всего?

### Точность по категориям

| № | Категория | Точность |
|---|-----------|----------|
| 1 | dresser | 70.93% |
| 2 | night_stand | 76.74% |
| 3 | desk | 79.07% |
| 4 | bathtub | 80.00% |
| 5 | sofa | 90.00% |
| 6 | monitor | 92.00% |
| 7 | table | 93.00% |
| 8 | bed | 96.00% |
| 9 | chair | 97.00% |
| 10 | toilet | 99.00% |

### Анализ ошибок классификации

dresser (70.93%) - чаще всего путается с night_stand (84%) и table (16%).

night_stand (76.74%) - путается с table (50%), dresser (40%), chair (5%).

desk (79.07%) - путается с table (61.1%), sofa (16.7%), night_stand (16.7%).

### Причины низкой точности

1. Визуальная схожесть объектов (dresser и night_stand - оба прямоугольные с ящиками)
2. Неполное представление вариаций в обучающих данных
3. Малое количество примеров для некоторых категорий
4. Высокая вариативность внутри класса
5. Потеря различительных признаков при сэмплировании до 1024 точек

## Вопрос 2: Влияние количества точек на качество модели

### Сравнение режимов

| Параметр | 512 точек | 1024 точки | 2048 точек |
|----------|-----------|------------|------------|
| Скорость обучения | Высокая | Средняя | Низкая |
| Требования к памяти | Низкие | Средние | Высокие |
| Детализация геометрии | Низкая | Достаточная | Высокая |
| Ожидаемая точность | −2-5% | Базовая | +1-2% |

### Выводы

Согласно оригинальной статье PointNet, модель устойчива к изменению количества точек. Оптимальный диапазон - 1024-2048 точек. При уменьшении до 512 точность падает на 2-5%, при увеличении до 2048 - растёт на 1-2%, но время обучения удваивается.

## Вопрос 3: Преимущества PointNet перед 3D CNN

### Сравнительная таблица

| Характеристика | PointNet | 3D CNN |
|----------------|----------|--------|
| Входные данные | Точки напрямую | Воксели |
| Параметры | 3.5M | 16.6M+ |
| Вычисления (FLOPs) | 440M | 3633M+ |
| Сложность | O(N) | O(R³) |
| Инвариантность к трансформациям | Встроенная (T-Net) | Через augmentation |
| Квантизация данных | Нет | Да |
| Устойчивость к пропускам | Высокая | Низкая |

### Ключевые преимущества

1. Прямая обработка точек - не требует вокселизации или проекций, сохраняет всю геометрическую информацию.

2. Вычислительная эффективность - в 8-140 раз меньше операций по сравнению с 3D CNN и Multi-View CNN.

3. Линейная масштабируемость - сложность O(N) позволяет обрабатывать миллионы точек.

4. Встроенная инвариантность - T-Net автоматически выравнивает входные данные без augmentation.

5. Устойчивость к неполным данным - потеря лишь 2-4% точности при 50% отсутствующих точек.

6. Интерпретируемость - можно визуализировать critical points и понять, какие точки влияют на решение.

7. Универсальность - одна архитектура для классификации, сегментации и детекции.
