# Задание 2b: Выделение областей в облаке точек

## Описание

Реализована сегментация облака точек с использованием различных фильтров на основе NumPy и визуализацией результатов с помощью Matplotlib.

## Реализованные фильтры

### 1. Фильтр по координатным границам (Bounding Box)

Параметры:
- X ∈ [20, 50]
- Y ∈ [30, 70]
- Z ∈ [10, 40]

Описание: Выделяет точки, находящиеся внутри заданного прямоугольного параллелепипеда. Использует логические операции для проверки принадлежности каждой координаты заданному диапазону.

Результаты:
- Исходное количество точек: 100000
- Отфильтровано точек: 3626
- Процент сохраненных точек: 3.63%

### 2. Фильтр по высоте

Параметры:
- Z > 80

Описание: Выделяет точки, находящиеся выше заданного порога по оси Z. Полезно для выделения верхних частей объектов или высотных элементов.

Результаты:
- Исходное количество точек: 100000
- Отфильтровано точек: 20041
- Процент сохраненных точек: 20.04%

### 3. Фильтр по расстоянию от точки

Параметры:
- Центр: (50, 50, 50)
- Радиус: 25

Описание: Выделяет точки в пределах сферы с заданным радиусом от центральной точки. Использует евклидово расстояние в 3D-пространстве для определения принадлежности точки сфере.

Результаты:
- Исходное количество точек: 100000
- Отфильтровано точек: 6690
- Процент сохраненных точек: 6.69%

### 4. Фильтр по круговой области в плоскости XY (дополнительный)

Параметры:
- Центр XY: (50, 50)
- Радиус: 30

Описание: Выделяет точки, находящиеся внутри цилиндра с неограниченной высотой. Проверяется только расстояние в плоскости XY, координата Z не учитывается. Полезно для выделения областей вокруг вертикальных объектов.

Результаты:
- Исходное количество точек: 100000
- Отфильтровано точек: 28344
- Процент сохраненных точек: 28.34%

## Анализ результатов

### BBox фильтр
Самый строгий фильтр, оставляющий только 3.63% точек. Ограничения по всем трем осям создают небольшой объем выборки, что делает этот фильтр полезным для точного выделения компактных областей.

### Фильтр по высоте
Оставляет 20% точек, находящихся в верхних 20% диапазона по оси Z. Это ожидаемый результат для равномерного распределения. Фильтр эффективен для выделения верхних частей объектов.

### Радиальный фильтр (сфера)
Сохраняет 6.69% точек в сфере радиуса 25 вокруг центра куба. Для куба размером 100×100×100 объем сферы составляет примерно 65450 единиц³, а объем куба 1000000 единиц³, что дает теоретическое соотношение 6.55%, что близко к полученному результату.

### Круговой фильтр XY
Наиболее щедрый фильтр, сохраняющий 28.34% точек. Цилиндр с радиусом 30 в плоскости XY имеет площадь основания πr² ≈ 2827, что составляет 28.27% от площади квадрата 100×100, что практически идентично полученному результату.
