# Задание 1b: Subsampling облака точек

## Ответы на вопросы

### 1. Как влияет размер выборки на визуальное качество облака?

При уменьшении размера выборки теряется детализация объекта:
5,000 точек (14% от оригинала) - общая форма зайца сохраняется, видны основные детали (уши, морда, туловище)
1,000 точек (3% от оригинала) - сохраняется только общий силуэт, мелкие детали теряются
6,778 точек (19% от оригинала) - хорошая детализация с равномерным распределением

Критический порог находится около 10% от оригинального облака - ниже этого значения геометрия объекта начинает существенно упрощаться

### 2. Как влияет размер вокселя в voxel_grid_subsampling на детализацию?

Размер вокселя напрямую определяет детализацию результата:
Маленький воксель (0.001-0.002) - высокая детализация, больше точек (~5,000-7,000)
Средний воксель (0.003-0.005) - сбалансированное соотношение детализации и размера (~2,000-4,000 точек)
Большой воксель (>0.01) - низкая детализация, потеря мелких деталей (<1,000 точек)

Для данного облака оптимальный размер вокселя: 0.002 - сохраняет структуру при разумном сокращении точек

### 3. Какой метод эффективнее по времени?

Результаты замеров производительности:

1. Random Subsampling: 0.004 секунды (самый быстрый)
   - Сложность: O(N)
   - Простой выбор случайных индексов

2. Voxel Grid Subsampling: 0.116 секунды 
   - Сложность: O(N log N)
   - Требует сортировки и поиска уникальных значений

3. Farthest Point Sampling: 3.215 секунды
   - Сложность: O(N^2)
   - Итеративный расчёт расстояний до всех точек

Вывод: Random Subsampling в 800 раз быстрее FPS, но качество результата хуже

### 4. Какой метод лучше сохраняет геометрию объекта?

Farthest Point Sampling лучше всего сохраняет геометрию: равномерное распределение точек по всей поверхности, сохранение границ и выступающих частей (уши зайца), минимальная потеря структурной информации

Voxel Grid Subsampling второе место: хорошее сохранение общей структуры, равномерное покрытие пространства, может терять детали в областях с низкой плотностью точек

Random Subsampling - худшее сохранение геометрии: неравномерное распределение, может пропустить важные области, результат недетерминирован
